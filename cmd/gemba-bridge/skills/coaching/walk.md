# Walk skill

A coaching skill that runs a Gemba walk — a structured, multi-topic
conversation that surfaces decisions, blockers, and trade-offs across
every active worker in the rig.

## When to use

- Daily / per-shift cadence: walk the rig before starting new work.
- After a major escalation: contextualize the escalation against
  every other in-flight piece.
- Before a stakeholder check-in: synthesize a status that's accurate
  without each worker having to write it up themselves.

## What it produces

A structured digest with per-topic sections (decisions needed,
blockers, in-progress notes, recently shipped). Pinned in the project
record so the next walk starts from where this one left off.
