# Pixel Avatar Spec Kit Fixture

This fixture is an original compact Spec Kit-style sample adapted from
the public Pixel Avatar feature shape in the ClawFace sample project:

https://github.com/oberones/ClawFace/tree/main/specs/005-pixel-avatar

It is intentionally shorter than the source material so the e2e run is
stable and easy to inspect. The important contract is the Spec Kit
artifact shape:

- `spec.md` contains `User Story #` headings and acceptance scenarios.
- `plan.md` provides feature-level planning context.
- `tasks.md` contains `T###`, `[P]`, and `[US#]` task markers.
